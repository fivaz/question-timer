# Question Timer

Track how long you spend on each question during a study or exam session.

## Setup

```bash
npm install
npm run dev
```

## Usage

1. Set **Started at** and **Questions planned**.
2. Optionally change the first question number — later rows auto-increment.
3. Tap **Tap when done** on each row when you finish that question.
4. Watch the progress bar, per-question duration, and average trend (color + arrow).

Finish times show as `HH:MM` but are stored with seconds for accurate averages.
